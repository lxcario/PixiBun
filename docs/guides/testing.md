## Preserve evidence

The [archive policy](../archives.md) retains the original completed audits and raw CI/browser/rollback payloads locally with verified hashes. They are ignored and absent from new source checkouts. Current qualifying summaries retain original source/build/run labels in [current status](../current-status.md). A failed post-run build guard excludes a passing pixel session from frozen-build qualification.

Future CI artifacts use immutable names containing revision, run ID and attempt with explicit 90-day retention. `npm run evidence:index -- --source <verification-output> --output artifacts/<new-index>.json` records hashes and bytes and refuses existing indexes, symlinks and credential directories. Failed and interrupted runs retain their original scope. Uploading or indexing is not proof of retrieval: keep the artifact ID, download digest and original-index comparison before accepting custody. Routine CI retention is not permanent storage; arrange a separately verified archive for evidence that must outlive it.

Routine screenshots use `test.info().outputPath('captures', filename)` beneath ignored Playwright output. Browser traces, ZIPs, reports and logs stay in `artifacts/`, `test-results/` or another ignored run directory. Select only lightweight, useful handbook illustrations for tracked `docs/assets/`; record their capture context separately. Do not copy a complete run into documentation.

To deliberately archive PNG captures locally, use `npm run evidence:publish -- --source <run-output> --destination artifacts/evidence-archive/<new-run-id> --run <run.json>`. The existing command name remains for compatibility. It requires command, runtime, browser, viewport, revision and verdict metadata, checks Git ignores the destination, creates a new directory and SHA-256 manifest, and refuses overwriting runs or publishing into source documentation. Record dirty status and test names; commit/build hashes identify release evidence more precisely than a dirty base revision.

A screenshot proves captured visible state rather than full interaction, timing, focus restoration, artist usefulness or device coverage. Scans leave manual conformance work in [the registry](../research/issue-registry.md). The requested compact bottom-left color dock retains seven recorded target-size findings; larger alternatives pass bounded keyboard checks, while manual touch/screen-reader equivalence remains open. Keep that tradeoff beside results.
