## Release fix

The prior live deployment served `/sw.js` as `text/plain`, which Chromium rejected as an unsupported service-worker MIME type. Commit `771218d` places JavaScript MIME, cache-control, and worker-scope headers on the route response. The local production build and live deployment were both checked after the fix.

## Deferred verification

- A browser update across two distinct deployed builds has not been exercised. Script version changes and activation cleanup have unit coverage, and current-build registration and offline reload have live Chromium evidence.
- Firefox, Safari, Android installation, and low-memory device behavior have not been rechecked in this sign-off.
- TestSprite could not run because its CLI and MCP are unavailable in this workspace. The Playwright suite above is the current browser regression evidence.
- GitHub Actions run details could not be inspected through the available unauthenticated GitHub access for this private repository. The canonical local gate and production deployment were verified directly.

These are accepted verification gaps, not claims of tested behavior. Recheck them as follow-up release work. The dynamic brush engine, Smart Effect schema expansion, pointer ergonomics, and other Phase 2+ features belong to a later release.
