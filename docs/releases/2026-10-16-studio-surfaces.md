Later the same day, the [Studio follow-up](2026-10-16-studio-follow-up.md) made every surface unfold with staggered content, rebuilt Live Preview on the shared panel and added one press motion for every control; the measurements below describe this branch's own revision. ## Why this is the default skin, not a Lab

Modals, popovers, menus, selects, disclosures and toasts all run through a few shared primitives (`ModalWrapper`, the new `FloatingPanel` and `Collapse`, and the surface stylesheet). A Lab gate in each primitive would fork every one of them into two code paths. Labs also default off under automation, so the end-to-end suites would never run the new paths. And Labs are hidden on Graphite and Plum, which still need these surfaces to work and look right. So motion and layout apply to every theme. The scene-only flourishes (2 px ink edge, hard drop) stay under `body.moon-ui`, and Graphite gets tighter corners through its own tokens.

## Motion system

All values come from [`src/lib/motion/springs.ts`](../../src/lib/motion/springs.ts) and reuse the Dynamic island's physics:

| Use | Spring or timing |
| --- | --- |
| Surface entrance (bloom) | Scale 0.95 → 1 on 600/26/0.9; blur 12 → 0 px over 340 ms; opacity 0 → 1 over 160 ms |
| Surface exit | 120 ms ease-in to scale 0.97, blur 8 px, opacity 0 |
| Height morph: grow, timeline | 460/25 (ζ≈0.58), bouncy |
| Height morph: collapse a disclosure | 420/31 (ζ≈0.76), lands without reopening |
| Sliding thumbs, chevrons, presses | 300/25/0.9 (the liquid tabs' SNAP) |
| Staggered content | 28 ms apart, rising 4 px out of 6 px blur, fully opaque |
| Reduced motion | 120 ms cross-fade; no scale, blur, travel or height spring |

- **Origin.** Every modal blooms from its own centre, so all dialogs open identically. Popovers and menus bloom from their trigger; that origin is computed from offset geometry, so the entrance scale doesn't skew it.
- **Closing.** A closing surface leaves the accessibility tree and becomes inert immediately. A closing modal also leaves the top layer, so the page is usable and focus returns while the panel melts away.
- **Height.** Changes are measured in a ResizeObserver callback (after layout, before paint) and sprung from the height that was on screen. Content is clipped while the height moves, never squeezed or scaled, and every scroll bar inside the moving surface is hidden until it settles. The morph starts only after the entrance completes; content that arrives during the entrance (the Projects list, a lazy tab) joins the bloom instead. Modals morph when steps or tabs change.
- **Native controls.** The `<select>` picker, `<details>` bodies, switches and chevrons use CSS `linear()` curves generated by `cssSpring()` from the same specs. `tests/surfaceMotion.test.ts` fails if the stylesheet drifts from the generator.
- **Live reduced motion.** `useReducedMotion` subscribes to the media query, as the island does, so changing the OS setting affects surfaces that are already open.

## Surfaces changed

- **Every modal** (`ModalWrapper`): the custom scrim fades in; the panel blooms from its centre and morphs its height after opening. The thirteen places that mount a dialog only while it is open (Projects, Help, Diagnostics, Canvas size, Import, Co-Draw, Command palette, Recovery, both color pickers, palette library and creator, onion skin settings) now sit inside `AnimatePresence`, so they melt away like the rest. Arrange workspace stays mounted and passes `isOpen`. The title mark is drawn in CSS, so "✦" is no longer part of the dialog's accessible name. Older content inside dialogs gets rounder corners, hairline frames instead of 2 px pixel frames, sans helper text and at least 10.5 px labels. Inputs, keys and code stay monospace.
- **View** (top rail): roomy two-column tiles with icon chips and state lines, grouped as Grids & guides, Check your art, Mirror and Panels. Composition guide, Color vision and Pattern brush became labeled dropdowns. Every toggle reports `aria-pressed`, and the accessible names that specs depend on are unchanged.
- **Studio menu:** action pills; each style card shows a tiny scene in that theme's sky, panel, lamp and accent colors. Night/Day is a segmented control whose thumb slides on SNAP. Labs, Tool previews and Tips are switch rows, and the radio groups keep their arrow-key behavior.
- **Start a New Drawing?:** six size tiles with grid previews and hints, a roving-tabindex radio group (arrows, Home, End), a soft callout instead of mono warning text, and pill buttons. It moved into [`NewDrawingModal`](../../src/components/modals/NewDrawingModal.tsx).
- **Timeline:** one persistent footer springs its height on 460/25 between the full strip and the compact bar, and never dips below the compact strip on the way down. The incoming content blooms in without scaling. Scene themes give the compact bar 48 px so its 28 px controls clear the sprocket rows. The floating status pill follows on the same curve, and a menu rising from the timeline now opens above the pill instead of under it.
- **Menus and flyouts:** File, zoom levels, preview speeds, tool-slot flyouts and the color flyout bloom and exit in place.
- **Selects:** still native `<select>` elements. Where `appearance: base-select` is supported (Chromium), the picker is a studio panel that springs open, with a gold dot on the chosen option. Other browsers keep the existing `moon-ui` select styling. In base-select browsers, an arrow key on a closed select opens the list; Enter or a click picks.
- **Disclosures:** inspector `PanelSection`s use `Collapse`, which is `hidden` at rest when closed and inert while closing. Native `<details>` spring open where `interpolate-size` is supported.
- **Notices:** the toast is a glass capsule that rises from the bottom edge. The save-problem card and the recovery banner bloom and exit. Their tones now come from theme tokens, which fixes near-white text that would have been unreadable on light themes.

The brush-size and tool-option panels in the top rail are unchanged. They belong to the Dynamic island Lab's expansion, and restyling them would change the island's measurements.

## Revision after review — 16 October

The first version aimed every modal's bloom at its opener, so dialogs opened from different directions. It also started height morphs during the entrance: the Projects list loading made the dialog grow while its body showed a scroll bar that vanished at the end. Several conditionally mounted dialogs also closed without the exit. The revision makes every dialog's entrance and exit identical, as described above. A per-frame check of Projects, New drawing, Canvas size, Export and Help (Tidepool Night and Sakura Day) recorded:

- scale 0.95 on the first frame and the origin at the panel's centre for all five;
- no morph frames during the entrance, and no frame with a visible scroll bar.

Projects still changes height once, two or three frames into the bloom, while blurred and fading in.

The revision's checks found one more defect. A dialog reopened while still melting away was revived by `AnimatePresence` but never re-entered the top layer, so clicks fell through to the canvas (seen in `importImageAndSheet`). Opening now follows presence, not mount; a unit test covers reopening mid-exit. The timeline's incoming content also lost its 4–6 px slide: a fractional offset made Chromium measure its 28 px buttons as 27.99994 px.

## Test changes

- New: [`tests/surfaceMotion.test.ts`](../../tests/surfaceMotion.test.ts) (spring math, CSS curve sync, reduced-motion coverage, placement and origin) and [`tests/components/SurfacePrimitives.test.tsx`](../../tests/components/SurfacePrimitives.test.tsx) (Collapse, FloatingPanel, modal exit and focus).
- New: [`tests/e2e/studioSurfaces.spec.ts`](../../tests/e2e/studioSurfaces.spec.ts), which samples motion per animation frame. It covers:
  - the popover origin and keyboard behavior;
  - the modal's scale staying within 0.94–1;
  - timeline overshoot past 128 px with no dip below the compact strip;
  - reduced motion;
  - native selects.
- `tests/setup.ts`: happy-dom left a cancelled Web Animation's `finished` rejection unhandled. The spec marks it handled, so the setup now does the same.
- Four component tests mocked `motion/react` with only a few exports. They now spread the real module and override the same stubs.
- `ModalWrapper.test.tsx` finds the title by heading name, since the glyph left the accessible name.
- `tests/e2e/studio.spec.ts` (layer reorder) now waits for `data-restoration-phase="active"` before adding a layer, as its sibling specs do. It clicked while the studio was still restoring, and the restored workspace replaced the new layer. The timing in this branch exposed that race; the app behavior is unchanged.
- `InspectorDeduplication.test.tsx` opens its closed section first. The old code hid the closed body with a Tailwind class that happy-dom never applied, so the test passed against a body no user could see.
