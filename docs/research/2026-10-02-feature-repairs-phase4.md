## Behavior

- Godot preflight and export share one normal-source predicate. Manual Normal Facets (normal tag), baked Normal Map (normal-map tag), and matching normal-map effects are admitted. Each exported frame needs exactly one source at full opacity with source-over blending. Hidden data layers are accepted; visible normal layers are excluded from diffuse when normal export is enabled. Ambiguous layers and missing buffers refuse the kit. Stored tangent-space channels are preserved.
- Welcome engine tabs offer Copy sample / Download sample. APNG/GIF offer Copy notes / Download notes (.txt), with a visible text-only explanation. Unsupported encoder examples, quantizer/dither claims, universal native-import claims and immediate URL teardown are removed. Notes wrap, clipboard failure is reported and success waits for the clipboard promise. Actual animation remains a Studio export.
- SVG now says Vector SVG and approximate contour conversion. The underlying contour/diagonal heuristic is unchanged; smooth edges are not promised to reconstruct the raster exactly or implement the full canonical paper.
- Selected-layer unique tiles now download one matching ZIP: tileset.png, zero-based tilemap.json and one-based Tiled map.tmj. Exact byte equality follows hash bucketing, retaining first-appearance row-major IDs and alpha. There is no rotation/flip deduplication or layer-composite bake. Both canvas dimensions must divide evenly by 8/16/32 px; partial edges are refused. Admission limits four million pixels, 4096 source tiles and 4096 px per side within the shared estimated CPU ledger.
- The tile export checks project/frame/layer/dimensions/tile size/edit revision/buffer version and registry revision/generation. Source changes disable Copy/Download, discard pending encoding and release retained reservations. A private ownership generation also prevents selecting an earlier frame or tile size from reviving a released result or stale pending UI state; a fresh scan is required. Cancel, missing/mismatched buffers, null PNG and 30-second timeout refuse publication. Source buffers are not created or resized to rescue an invalid export.
- Current feature rows, issues H04–H07, guides, architecture and export contract describe the repaired behavior. Six actual UI captures replace affected guide illustrations, with hashes and separate run scopes in the [capture record](../assets/screenshots/2026-10-02-feature-repairs-phase4/run.json). Older screenshots/evidence retain their original bytes.

## Failures and corrections

The first new editor run passed two cases and failed three assertions: the test used normals.png instead of the existing normal.png filename and the wrong rect field; an alert locator also matched Next.js's route announcer; the welcome selector used button instead of tab. Those assertions were corrected. No product failure was inferred from them.

A gate stopped on the local test-only codec control's TypeScript cast. A subsequent gate reached unit tests and found two existing component assertions using the old Download / Copy Code labels and immediate URL revocation. These now check Download sample / Copy sample and delayed revocation. The final gate passed. A later capture attempt tried to click a closing hover-preview button and timed out; Escape is the supported dismissal and produces unobstructed final tile captures.

Two complete compiled attempts each passed 26 cases and failed the same WebKit manual-normal comparison. Native ZIP/Pillow inspection showed the PNG contained the stored diffuse sample [1,255,0,255], while the browser's display-profile decode returned [2,255,0,255]. Normal channels were intact. createImageBitmap with colorSpaceConversion none still produced the extra conversion in this environment. The test now decodes exported native RGB/RGBA samples independently through PNG filters 0–4. Fixed RGB/RGBA vectors were checked in Pillow and Vitest. Source inputs still follow the actual import path; exact equality remains, without tolerance. A native-decoder run passed 27 cases before the ownership repair. The final compiled run repeated all 27 against the ownership repair and passed. Application export code was unchanged by this comparison correction. Display/profile handling in arbitrary viewers is not certified.

A return-to-original source regression exposed a genuine product bug: changing frame/tile size released the bundle, but returning to its earlier key re-enabled its button. Component ownership now advances across source changes. The regression first failed, then passed in the final seven-case editor run and all three compiled browsers. A gate also caught a temporarily missing phase 4 evidence index during finalization; the index was restored before the final passing gate. These diagnostics are retained.

The Godot oracle reads native PNGs from the unpacked test project, which produces two Image.load_from_file warnings about exported Godot packages. That reading is test-only; the actual generated scene uses imported Texture2D resources. Both the earlier development-kit and final compiled-kit resource/pixel checks had no failures. It does not establish rendered lighting or packaged-game behavior.
