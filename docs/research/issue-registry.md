## Outstanding research and qualification

| Area | Required evidence |
| --- | --- |
| Accessibility | Seven compact target findings remain; qualify manual keyboard, screen-reader and touch equivalence on named devices. Automated scans do not establish conformance. |
| Artist usefulness and learning | Recruit participants, record consent, build/task order and actual observations. Automated dry-runs do not close this work. |
| Physical devices and Safari | Qualify pen/touch input, browser/device combinations and actual Safari, including legacy-Blob rollback. |
| Long sessions and memory | Measure peak, retained and active scratch memory plus decoder/GPU/worker behavior on named low-memory devices. Earlier periodic sessions failed their final compiled-build guard. |
| Real collaboration | Exercise two-machine network modes, concurrent paints/locks, structure refusal, disconnect/reconnect and congestion. |
| Motion quality and responsiveness | Evaluate large parts, arbitrary-angle detail, crop feedback, temporal/artwork quality and end-to-end latency on named hardware/builds. Multi-part rigs and source-rebinding formats remain proposals. |
| Export consumers | Qualify additional actual game importers, video decoders and codecs beyond existing fixtures. |
| Production release/update/rollback | Record deployed revision, host asset retention, cache transitions and long-lived tabs; bounded local compatible-build results do not qualify the host or approve release. |
| Historical diagnostics | Retain unexplained native Chromium crashes, older-build cold controller failures and instrumented timing failures with their original verdicts. Later passing runs do not establish their cause. |
| External assertions | Keep the [TestSprite plan registry](testsprite-plan-registry.md) separate from terminal verdicts. Missing drawing prerequisites or incomplete assertions are missing coverage. The current milestone uses native verification. |

The single rigid-part workflow has reversible pose controls and asynchronous preview/bake with cancellation, scoped ownership/memory regression checks and saved definitions. General motion generation and device/artist qualification remain open.
